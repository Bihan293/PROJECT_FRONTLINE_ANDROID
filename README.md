# PROJECT FRONTLINE — Android (v0.2)

Мобильный тактический 3D FPS шутер для Android, созданный на Three.js и упакованный в нативное полноэкранное приложение Android с аппаратным ускорением.

## 📦 Скачать готовый APK
Готовая сборка автоматически собирается в GitHub Actions при каждом релизе или пуше в `main`.

👉 **[Скачать APK из раздела Releases](https://github.com/Bihan293/PROJECT_FRONTLINE_ANDROID/releases)**

---

## 🎮 Управление на телефоне
* **Левый джойстик:** Движение (ходьба / бег).
* **Правая часть экрана:** Плавный обзор камеры (мультитач).
* **Кнопки действий:**
  * **ОГОНЬ** — стрельба.
  * **ПРИЦЕЛ** — приближение (зум).
  * **ПРЫЖОК** и **ПРИСЕСТЬ** — смена позиции.
  * **ОСКОЛОК** и **ДЫМ** — бросок гранат.
  * **ЗАРЯД** (⟳) — перезарядка магазина.
  * **БИНТ** (✚) — остановка кровотечения и восстановление здоровья.
  * **Слоты оружия (1-4):** выбор АК-74, Дробовика, СВ или ПМ.

---

## 🛠 Особенности проекта
1. **Полная автономность:** 3D-движок Three.js полностью встроен в локальные ассеты (`js/three.module.js`), подключение к интернету для игры не требуется.
2. **Аппаратное ускорение:** Android WebView использует `WebViewAssetLoader` и виртуальный HTTPS-хост для бесшовной работы WebGL, шейдеров и аудио без ограничений file://.
3. **Автоматическая CI/CD сборка:** Настроен пайплайн GitHub Actions (`.github/workflows/build-apk.yml`), который компилирует APK и прикрепляет его к релизу.

## 🔨 Сборка из исходников
Если вы хотите собрать APK локально через терминал или Android Studio:

```bash
# Клонировать репозиторий
git clone https://github.com/Bihan293/PROJECT_FRONTLINE_ANDROID.git
cd PROJECT_FRONTLINE_ANDROID

# Собрать APK (требуется Java 17)
./gradlew assembleRelease
```
Готовый файл появится в:
`app/build/outputs/apk/release/app-release.apk`
